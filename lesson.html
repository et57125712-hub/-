單元一｜免疫系統總覽與先天防線

建議時間：50分鐘｜搭配闖關：概念闖關第22、28、29、54、60題；國考特訓第4、5題

學習目標

  1. 說出先天免疫與後天免疫的核心差異。
  2. 解釋皮膚、黏膜、正常菌叢、嗜中性球、巨噬細胞、發炎反應與干擾素的角色。
  3. 能將「紅、腫、熱、痛」連結到臨床傷口觀察。

老師板書稿

  • 免疫系統不是只有抗體：第一線是屏障，第二線是吞噬與發炎，第三線才是專一性淋巴球反應。
  • 先天免疫的特色是快、廣、不專一；後天免疫的特色是慢、準、有記憶。
  • 傷口紅腫熱痛不是單純「惡化」，而是血管擴張、通透性增加與白血球移動的表現；但若伴隨膿、發燒、擴散性紅腫，就要提高感染警覺。

核心概念比較表

概念學生要懂的意思護理/臨床連結
皮膚、黏膜、正常菌叢阻擋病原進入，屬第一道防線破皮、導管、手術傷口會讓屏障被打開
嗜中性球急性感染前線吞噬細胞細菌感染、膿液與白血球上升常會一起思考
單核球/巨噬細胞吞噬、清除、分泌細胞激素，也可參與抗原呈現慢性發炎、組織修復、抗原呈現都會遇到
IFN-alpha / IFN-beta使鄰近細胞進入抗病毒狀態病毒感染初期的防毒更新
淋巴結過濾淋巴液，讓免疫細胞集合與反應感染附近淋巴結腫大可視為免疫反應線索

臨床情境

病人有下肢蜂窩性組織炎，護理學生觀察到局部紅、腫、熱、痛與白血球上升。請學生判斷：哪些屬於先天免疫反應？哪些現象提示可能需要進一步醫療處置？

課堂任務

兩人一組畫出「病原入侵到局部發炎」四格流程：屏障受損 -> 先天辨識 -> 血管反應 -> 白血球到場。每格限20字，訓練學生把抽象文字變成可講給病人聽的語言。

搭配闖關題目

  • 第22題 病原想闖進人體，第一個遇到的「門口保全」通常是誰？
    答案：皮膚、黏膜與正常菌叢｜皮膚、黏膜與正常菌叢屬先天免疫第一道防線。
  • 第28題 感染現場第一波衝到前線、最愛吞細菌的是哪位快腿選手？
    答案：嗜中性球｜嗜中性球常在急性感染初期快速抵達並吞噬細菌。
  • 第29題 被病毒入侵的細胞會向鄰居發布「防毒更新」，最常用哪一組訊號？
    答案：IFN-α與IFN-β｜第一型干擾素可使鄰近細胞進入抗病毒狀態。
  • 第54題 淋巴結最像免疫系統的哪種設施？
    答案：過濾淋巴液並讓免疫細胞集合的基地｜淋巴結可過濾淋巴液，並提供免疫細胞反應場所。
  • 第60題 傷口局部出現紅、腫、熱、痛，這是哪一種經典套餐？
    答案：發炎反應｜紅、腫、熱、痛是常見局部發炎表現。

單元二｜抗原呈現、MHC與淋巴細胞活化

建議時間：50分鐘｜搭配闖關：國考特訓第6、7、8、12、13題；概念闖關第21、24、25、26、46、61題

學習目標

  1. 分辨外源性抗原與內源性抗原的呈現路徑。
  2. 說明MHC class II對CD4+ T細胞、MHC class I對CD8+ T細胞的關係。
  3. 能描述B細胞活化到漿細胞分泌抗體的基本流程。

老師板書稿

  • 最容易混淆的一句話：外來抗原常走MHC II找CD4；細胞內抗原常走MHC I找CD8。
  • B細胞不是一開始就大量分泌抗體，活化後分化成漿細胞才像抗體工廠。
  • Treg像免疫反應的煞車，協助維持自體耐受，避免免疫系統把自己人打成敵人。

核心概念比較表

概念學生要懂的意思護理/臨床連結
MHC class I幾乎所有有核細胞表現；呈現內源性抗原給CD8+ T細胞病毒感染細胞、腫瘤細胞被毒殺型T細胞監控
MHC class II抗原呈現細胞表現；呈現外源性抗原給CD4+ T細胞樹突狀細胞、巨噬細胞、B細胞把外來抗原情報送上桌
CD4+ T細胞協助與指揮免疫反應HIV主要破壞此類細胞，免疫指揮鏈受損
CD8+ T細胞毒殺受感染細胞與腫瘤細胞辨識MHC I上的異常抗原
Treg抑制過度反應、維持自體耐受自體免疫與免疫調節概念會連到此處

臨床情境

一位病人感染病毒後，受感染細胞把病毒胜肽放到MHC class I上；另一位病人的樹突狀細胞吞噬細菌後，將抗原放到MHC class II上。請學生分別配對CD8+與CD4+ T細胞。

課堂任務

用「身分證與通行證」比喻MHC：請學生在白板上畫兩條路徑，一條是MHC I/CD8，另一條是MHC II/CD4，並各寫一個臨床例子。

搭配闖關題目

  • 第21題 免疫城市要選出「抗原情報三人組」，哪一組最有資格上台報告？
    答案：樹突狀細胞、巨噬細胞、B細胞｜典型抗原呈現細胞包括樹突狀細胞、巨噬細胞與B細胞。
  • 第24題 CD4⁺ T細胞在免疫會議中，只認哪一張「通行證」上的抗原胜肽？
    答案：MHC class II｜CD4⁺ T細胞主要辨識MHC class II所呈現的抗原胜肽。
  • 第25題 病毒感染細胞被CD8⁺ T細胞鎖定時，關鍵辨識牌是哪一張？
    答案：MHC class I｜CD8⁺ T細胞主要辨識MHC class I所呈現的內生性抗原。
  • 第26題 B細胞要轉職成「抗體工廠」，最後會變成哪一種細胞？
    答案：漿細胞｜活化B細胞可分化為漿細胞並大量分泌抗體。
  • 第46題 哪一群T細胞像免疫班上的風紀股長，專門壓住過度反應？
    答案：Treg｜調節型T細胞可抑制過度免疫反應並維持自體耐受。

單元三｜抗體、補體、疫苗與免疫記憶

建議時間：50分鐘｜搭配闖關：國考特訓第9、10、11題；概念闖關第23、27、31、32、33、56、57、58、63、64、66、67、68、69、70題

學習目標

  1. 比較IgM、IgG、IgA、IgE在免疫反應中的代表功能。
  2. 說明補體與膜攻擊複合體MAC的概念。
  3. 分辨主動免疫、被動免疫、初次反應與二次反應。

老師板書稿

  • IgM：初次反應早期常先登場；IgG：血清中重要且能通過胎盤；IgA：黏膜與初乳；IgE：第一型過敏。
  • 補體像一組可被啟動的連鎖反應，最後可形成MAC在病原表面打洞。
  • 疫苗重點不是「立刻給抗體」，而是訓練身體產生免疫反應與記憶。

核心概念比較表

概念學生要懂的意思護理/臨床連結
IgM初次免疫反應早期常見；五聚體新感染早期線索常會想到
IgG二次反應重要；可通過胎盤；減敏治療可增加阻斷型IgG胎兒被動免疫、疫苗後記憶反應
IgA黏膜與分泌液代表抗體初乳、腸道、呼吸道黏膜防護
IgE與肥大細胞及第一型過敏反應相關花粉、氣喘、過敏性休克
補體MACC5b-C9形成膜攻擊複合體細菌溶解、防禦與發炎反應

臨床情境

新生兒喝初乳後得到IgA保護；胎兒經胎盤獲得母體IgG；學生接種疫苗後產生自己的記憶細胞。請學生判斷哪個是天然被動免疫，哪個是人工主動免疫。

課堂任務

抗體角色卡：每組抽一張IgM/IgG/IgA/IgE卡，用30秒說明「我在哪裡出現、我保護誰、臨床遇到我時要想到什麼」。

搭配闖關題目

  • 第23題 同一支疫苗第二次登場，免疫系統像開外掛，最可能出現哪種反應？
    答案：反應較快且以高親和力IgG為主｜二次免疫反應更快、更強，且常以高親和力IgG為主。
  • 第31題 學生打完疫苗，身體自己練出抗體與記憶細胞，這屬於哪一種免疫？
    答案：人工主動免疫｜疫苗刺激自身產生免疫反應與記憶，屬人工主動免疫。
  • 第32題 胎兒在胎盤收到媽媽寄來的IgG禮包，屬於哪種免疫？
    答案：天然被動免疫｜母體IgG經胎盤提供胎兒被動免疫。
  • 第33題 新生兒喝初乳，腸道黏膜最想收到哪一種抗體？
    答案：分泌型IgA｜初乳富含分泌型IgA，可保護腸道黏膜。
  • 第56題 初次體液性免疫反應中，最早大量登場的抗體是？
    答案：IgM｜初次免疫反應早期主要產生IgM。

單元四｜過敏反應、輸血與急症照護

建議時間：50分鐘｜搭配闖關：國考特訓第1、14、15、16題；概念闖關第36、37、38、39、40、41、42、43、55題

學習目標

  1. 分辨第一至第四型過敏反應的典型機轉與例子。
  2. 連結ABO不合、Rh溶血與第二型過敏反應。
  3. 說出過敏性休克時優先處置概念與腎上腺素的重要性。

老師板書稿

  • 第一型：IgE、肥大細胞、組織胺，反應快；第二型：抗體攻擊細胞表面抗原；第三型：免疫複合物沉積；第四型：T細胞媒介，反應較慢。
  • 過敏性休克的核心是全身性血管擴張、通透性增加、呼吸道問題與血壓下降；第一支救命藥要想到腎上腺素。
  • ABO不合輸血不是單純血型背誦，而是抗體攻擊紅血球造成急性溶血。

核心概念比較表

概念學生要懂的意思護理/臨床連結
第一型IgE、肥大細胞、組織胺，立即型花粉過敏、氣喘、過敏性休克
第二型抗體攻擊細胞表面抗原ABO不合輸血、重症肌無力部分機轉
第三型免疫複合物沉積造成組織傷害SLE部分傷害機轉
第四型T細胞媒介，延遲型接觸性皮膚炎、結核菌素反應
Rh溶血已致敏Rh陰性母親之IgG攻擊Rh陽性胎兒紅血球產科與新生兒照護重要概念

臨床情境

病人接觸過敏原後出現呼吸困難、低血壓與全身蕁麻疹。請學生用「觀察-判斷-優先處置」三欄寫下：看到什麼、想到什麼、第一步要做什麼。

課堂任務

四型過敏配對賽：教師發下疾病/例子卡，學生要貼到第一、二、三、四型欄位，並用一句話說出理由。

搭配闖關題目

  • 第39題 花粉一出場，幾分鐘內就鼻癢、流鼻水甚至氣喘，這是哪一型過敏？
    答案：第一型｜花粉過敏常屬IgE媒介的第一型過敏反應。
  • 第40題 ABO不合造成急性溶血性輸血反應，分類上最接近哪一型？
    答案：第二型｜抗體攻擊紅血球表面抗原屬第二型過敏反應。
  • 第41題 SLE中免疫複合物像垃圾塞滿組織，這屬哪一型過敏反應？
    答案：第三型｜免疫複合物沉積造成傷害是第三型過敏反應。
  • 第42題 戴了某種手套後隔天出現接觸性皮膚炎，最符合哪一型？
    答案：第四型｜接觸性皮膚炎主要由致敏T細胞媒介，屬第四型。
  • 第43題 病人接觸過敏原後迅速呼吸困難、低血壓、全身蕁麻疹，第一支救命藥是？
    答案：腎上腺素｜全身性過敏反應首選腎上腺素。

單元五｜自體免疫、免疫缺乏、移植與腫瘤免疫

建議時間：50分鐘｜搭配闖關：國考特訓第2、17、18、19、20題；概念闖關第30、44、45、47、48、49、50、51、52、53、65題

學習目標

  1. 說明自體免疫的基本概念，並以Graves disease、重症肌無力、SLE為例。
  2. 說出HIV主要攻擊CD4+ T細胞及其臨床意義。
  3. 連結MHC、移植排斥、NK細胞與腫瘤免疫監視。

老師板書稿

  • 自體免疫的核心不是免疫力太弱，而是敵我辨識失準。
  • HIV拆掉免疫指揮中心，主要破壞CD4+ T細胞。
  • 腫瘤若降低MHC class I表現，可能躲過CD8監視，但會讓NK細胞覺得可疑。

核心概念比較表

概念學生要懂的意思護理/臨床連結
Graves disease抗TSH受體抗體刺激甲狀腺像把油門一直踩著
重症肌無力抗乙醯膽鹼受體自體抗體影響神經肌肉傳導肌肉無力與疲勞感
SLE自體抗體與免疫複合物沉積多系統表現，腎臟與皮膚等都可能受影響
HIV破壞CD4+ T細胞免疫協調能力下降，伺機性感染風險上升
移植排斥MHC差異引發免疫辨識器官移植後需監測排斥與感染風險

臨床情境

腎移植病人返診時，學生需要同時想到兩件事：一是排斥風險，二是免疫抑制後感染風險。請學生寫出各自可能觀察到的警訊。

課堂任務

自體免疫病例任務：每組選Graves disease、重症肌無力、SLE之一，完成「攻擊目標-機轉-症狀線索-護理觀察」四欄表。

搭配闖關題目

  • 第44題 甲狀腺被自體抗體當成油門一直踩，最符合哪種疾病機轉？
    答案：Graves disease中的抗TSH受體抗體刺激｜Graves disease常由自體抗體刺激TSH受體造成甲狀腺亢進。
  • 第45題 自體抗體把乙醯膽鹼受體「貼封條」，病人最可能出現哪種疾病？
    答案：重症肌無力｜重症肌無力與抗乙醯膽鹼受體自體抗體有關。
  • 第47題 HIV最愛拆掉免疫指揮中心，主要攻擊哪一類細胞？
    答案：CD4⁺ T細胞｜HIV主要感染並破壞CD4⁺ T細胞。
  • 第49題 移植物被認成外來戶口，最關鍵的身分差異是哪一類分子？
    答案：MHC｜MHC差異是移植排斥的重要原因。
  • 第51題 腫瘤想躲監視，最可能偷偷做哪件事？
    答案：降低腫瘤抗原或MHC表現｜降低抗原或MHC表現可幫助腫瘤逃避免疫監視。
